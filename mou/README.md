# NLnet grant documentation — Dasher v6 (2026-04-069)

This directory holds the public copies of the Memorandum of Understanding and
the project plan (Annex I) for NLnet grant **2026-04-069** (NGI0 Commons Fund,
April 2026 call, €50,000).

- `2026-04-069-MoU.md` — public copy of the MoU. Personal data (addresses,
  email addresses, signatures) is redacted; the signed original with full
  details is held privately by NLnet.
- `2026-04-069-plan.md` — the project plan. Tasks and milestones are
  publicly verifiable on github.com/dasher-project; payment amounts attach to
  milestones, not to individuals.

Payments under this grant are charitable donations from Stichting NLnet for
completed milestones (Request for Payment, 100% completion). No VAT applies.
